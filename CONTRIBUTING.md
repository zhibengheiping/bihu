# Contributing Guidelines

## Copyright and Licensing

Be aware that different directories use different open source
licenses. For any license in the GPL family, a specific version must
be designated (similar to how Linux does it), and upgrading to a later
version is prohibited.

The system call interface is licensed under Apache. libc is licensed
under LGPL. All other operating system components are licensed under
AGPL.

libc must not depend on any other OS components. Other OS components
may dynamically link to libc, but must not rely on libc's internal
implementation.

**Do not submit any code generated by AI assistants.**

You are required to sign off your contributions using the Developer
Certificate of Origin (DCO), confirming that you have the right to
contribute and that you grant permission under the same license terms.

For each new source file, include an SPDX license line at the very
top, for example:

```
SPDX-License-Identifier: AGPL-3.0-only
```

For every file you modify, add your copyright notice:

```
Copyright (C) [year] [name/organization]
```

Your commit message must end with a Signed-off-by line:

```
Signed-off-by: name <email>
```

You can use git commit -s to add this automatically.

Adding this signature means you agree to the
[DCO](https://developercertificate.org/).

If you are contributing as part of your employment (i.e., a
work-for-hire) for a company or other organization, please use your
corporate or organizational email address for the commit, and provide
a legally valid authorization document from that organization before
your first contribution.
